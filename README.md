# MeshViewer
3D Viewer

3D Viewer — приложение для Windows для быстрого просмотра и работы с трёхмерными моделями.

Программа распространяется в скомпилированном виде для Windows.

Возможности

Просмотр трёхмерных моделей, вращение и масштабирование сцены, анализ геометрии и другие инструменты работы с 3D-моделями.

Актуальная версия программы находится в разделе Releases этого репозитория.

Рекомендуется скачивать программу только с официальной страницы этого репозитория.

Системные требования

Windows 10/11, 64-bit.
